# Third-party software and credits

This project is a PS4 adaptation of **Sp9nky/unofficial-stremio-ps5-port**, licensed under GNU GPL v3.0.

The build and application use third-party open-source projects including:

- **OpenOrbis PS4 Toolchain** — PS4 homebrew toolchain and packaging tools.
- **PacBrew** — OpenOrbis packages and PS4 port libraries.
- **SDL2** — windowing, audio and rendering abstraction.
- **RmlUi** — user interface library.
- **FFmpeg** — media demuxing, audio/video handling and software decoding paths.
- **libcurl** — HTTP/HTTPS networking.
- **mbedTLS** — TLS support used by the PacBrew libcurl package.
- **FreeType** — font rasterization.
- **FriBidi** — bidirectional text processing.
- **libwebp** — WebP image decoding.
- **zlib / bzip2 / libpng** and other transitive PacBrew dependencies.

The upstream project also includes or credits additional components, artwork, fonts and libraries. Their original copyright notices and licenses remain applicable.

No proprietary Sony SDK, keys, firmware files or Sony source code are distributed by this repository.
